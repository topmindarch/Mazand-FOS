# Security Policy — Mazand FOS

## گزارش آسیب‌پذیری

گزارش آسیب‌پذیری را در Issue عمومی منتشر نکنید. از مسیر خصوصی توافق‌شده با مالک مخزن استفاده کنید. تا وقتی کانال امنیتی مشخص نشده، در مستندات داخلی `docs/18_SECURITY_AND_PERMISSIONS_FA.md` مسیر جایگزین را ثبت کنید؛ آدرس ایمیل یا کانال ساختگی درج نکنید.

## قواعد نگهداری داده

- هیچ credential یا داده واقعی بانکی/مالی وارد Git نشود.
- فایل `.env` و فایل‌های تنظیماتی دارای secret از ابتدا ignore شوند.
- نمونه‌ها synthetic باشند.
- logها token، رمز، اطلاعات بانکی کامل یا داده شخصی غیرضروری را ثبت نکنند.
- دسترسی سرویس بر پایه least privilege باشد؛ مخفی‌کردن دکمه جایگزین authorization سمت سرور نیست.
- Remote access از VPN یا gateway احراز هویت‌شده عبور کند؛ دیتابیس مستقیماً روی اینترنت منتشر نشود.
